# التكاليف التربوية 🌱

موقع بسيط لمتابعة التكاليف التربوية لطلاب الأكاديمية — نقاط، Streak، لوحة صدارة لكل مجموعة، رسائل تشجيع عشوائية.

**نسخة مبسّطة عمدًا**: التطبيق نفسه بيعمل حاجة واحدة بس وبيعملها كويس — تجربة الطالب اليومية، ومتابعة بسيطة للمعلم والمسؤول. أي حاجة إدارية نادرة (زي إضافة عضو جديد أو مجموعة جديدة) بتتعمل من لوحة Supabase الجاهزة مجانًا، بدل ما نبني واجهة مخصصة لكل حاجة.

## التكلفة: 0 جنيه، طول ما فضلت أكاديميتك صغيرة (Supabase + Vercel لهما حدود مجانية سخية جدًا لحجمك).

---

## الإعداد (مرة واحدة فقط)

### 1) Supabase
1. سجّل مجانًا على [supabase.com](https://supabase.com) وأنشئ مشروعًا جديدًا.
2. من **Project Settings > API** انسخ: `Project URL` و `anon public key`.
3. من **SQL Editor**، افتح استعلامًا جديدًا، الصق **كل محتوى ملف `supabase/schema.sql`**، وشغّله. ده بينشئ كل حاجة محتاجها التطبيق دفعة واحدة.

### 2) التشغيل محليًا
```bash
npm install
cp .env.local.example .env.local
# افتح .env.local واملأ Project URL و anon key من الخطوة اللي فاتت
npm run dev
```
افتح `http://localhost:3000`.

### 3) جرّبه ببيانات جاهزة (اختياري)
```bash
npm run seed:demo
```
بينشئ أدمن، معلمين، 6 طلاب، وأسبوع كامل من الإنجازات، عشان تشوف الموقع شغال فورًا. كل الحسابات بكلمة مرور `Demo@12345` (التفاصيل في نهاية الملف).

### 4) النشر (مجانًا)
ارفع المشروع على GitHub → استورده في [Vercel](https://vercel.com) → ضيف نفس متغيرَي `.env.local` في إعدادات Vercel → Deploy.

## إزاي تضيف طالب / معلم / مجموعة جديدة (بدون كود، من لوحة Supabase)

كل ده بيتعمل من لوحة Supabase نفسها (اللي فتحتها في الخطوة الأولى)، مش من داخل الموقع.

### إضافة عضو جديد (طالب أو معلم)
1. من قائمة Supabase الجانبية: **Authentication** → **Users** → **Add user**.
2. حط الإيميل وكلمة مرور، وفعّل **Auto Confirm User** (عشان يقدر يدخل فورًا من غير تأكيد إيميل).
3. اضغط Create. هيتولّد للمستخدم صف تلقائي في جدول `profiles` بدور "طالب" افتراضيًا.
4. روح **Table Editor** → جدول **profiles** → دوّر على الصف بتاع المستخدم الجديد (بالإيميل أو بالترتيب الزمني) → عدّل عمود **role** (student / teacher / admin) وعمود **full_name** (اسمه)، ولو طالب حط **group_id** (هتلاقي الـ id بتاع المجموعة من جدول groups).

### إضافة مجموعة جديدة
1. **Table Editor** → جدول **groups** → **Insert row**.
2. اكتب `name` (اسم المجموعة) و `emoji` (أي رمز تحبه) و `teacher_id` (انسخه من جدول profiles بتاع المعلم المسؤول).

هتلاقي الـ Table Editor شبه Excel تمامًا — صفوف وأعمدة، تعديل مباشر بالضغطتين.

## اللي بتعمله من داخل الموقع نفسه

- **إنشاء التكاليف وتعديلها** ورسائل التشجيع: من لوحة المعلم أو المسؤول → "التكاليف" (ده الجزء الوحيد اللي فيه شاشة مخصصة، لأنه معقد شوية على جدول Excel عادي).
- **متابعة الطلاب**: من لوحة المعلم → "طلابي".
- **نظرة عامة ولوحات الصدارة**: من لوحة المسؤول.
- الطالب بيستخدم الموقع بشكل يومي من هاتفه: تكاليف اليوم، نقاطه، ترتيبه.

## كيف يعمل النظام من الداخل (لو حبيت تفهم أو تعدّل لاحقًا)

- كل الصلاحيات مطبّقة داخل قاعدة البيانات نفسها (وليس فقط بإخفاء أزرار في الواجهة)، فحتى لو حد حاول يتحايل، النظام بيرفض. اتعمله اختبار فعلي محلي — موجود فى `test/` لو حابب تتأكد بنفسك.
- عند إنجاز تكليف بيتكرر أكتر من مرة (زي الصلاة 5 مرات)، النقاط بتتحسب بالتناسب (3 من 5 = 60% من النقاط)، مش أضعاف.
- نسبة الالتزام والـ Streak ولوحة الصدارة بتتحسب تلقائيًا كل ما حد يفتح الصفحة.
- رسائل التشجيع بتتختار عشوائيًا من القائمة اللي حطّها المعلم لكل تكليف.

## هيكل المشروع

```
app/student/    واجهة الطالب (الأهم)
app/teacher/     متابعة بسيطة + إدارة التكاليف
app/admin/       نظرة عامة + إدارة التكاليف + لوحات الصدارة
supabase/schema.sql   قاعدة البيانات بالكامل، ملف واحد
scripts/          بيانات تجريبية (إنشاء/حذف)
test/             اختبار محلي اختياري للتأكد من الصلاحيات (تحتاج PostgreSQL محليًا، مش لازم للتشغيل العادي)
```
